# 学习委员竞选 · 学同行

七页中文网页演示，原生 HTML / CSS / JavaScript，无第三方依赖和外部字体。支持电脑、手机、键盘翻页、触摸滑动、全屏和打印。

## 使用

直接打开 `index.html`，或运行 `python -m http.server 8080` 后访问 `http://localhost:8080`。

- ← / →、PageUp / PageDown：翻页；空格：下一页。
- Home / End：首页 / 末页；F：全屏；Esc：退出全屏。
- 手机左右滑动或使用底部按钮。链接 `#3` 可直达第三页。
- 浏览器打印可导出完整七页（横向，建议开启背景图形）。

## 个性化

在 `app.js` 的 `profile` 填写姓名与班级。当前内容是竞选提案，不包含未经确认的成绩、获奖或个人经历。可在 `index.html` 补充真实经历，并按实际意愿调整工作承诺。

## 部署

上传 `index.html`、`style.css`、`app.js` 到静态网站目录即可。使用相对资源路径，支持子目录部署。服务器凭据不要写入仓库。

## 验证

`node --check app.js` 检查 JavaScript 语法。浏览器需核验七页导航、首尾边界、全屏、移动端布局和资源加载。
