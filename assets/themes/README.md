# 插画主题素材

三张插画由内置 ImageGen 为本项目生成，均为原创阅读场景，无可读文字或外部游戏角色。生成图保持原始像素，网页以 CSS 裁切适配封面、致谢页和主题缩略图。

| 文件 | 场景 | 实际尺寸 |
| --- | --- | --- |
| `forest.png` | 晨光、林窗、植物与手账书桌 | 1122 × 1402 |
| `ocean.png` | 海岸、晴空、书本与贝壳 | 1254 × 1254 |
| `lunar.png` | 星月阅读剧场、发光书页 | 1254 × 1254 |

完整提示词见 [森野及猫头鹰、海獭](forest-prompts.json)、[海岸、星月及月兔](ocean-lunar-prompts.json)。配套透明桌宠在 `../pets/`。
